Репозиторий содержит три лработы, посвящённые архитектуре, обучению и применению нейронных сетей. Проекты последовательно охватывают:
- **ML8**: Полносвязные нейронные сети (MLP) для табличных данных
- **ML9**: Сверточные нейронные сети (CNN) для классификации изображений
- **ML10**: Рекуррентные нейронные сети (RNN/LSTM/GRU) для работы с последовательностями

Каждый модуль включает код модели, скрипты обучения/оценки, визуализацию метрики.
